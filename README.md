# slimelands

スライムたちと村を育て、ダンジョンを攻略する2D カード×オートバトルゲームです。(開発中)

![ダンジョン戦闘のスクリーンショット](docs/images/battle.png)

## コンセプト

「Stacklands」のカードを重ねて合成する村づくりと、「ゆっくり育てていってね」のような放置寄りの
ダンジョン攻略を組み合わせたゲームです。村人はすべてスライム。アニメーション制作の負担を抑えつつ、
配合や進化で多様な個体を楽しめるよう、キャラクターをスライムに絞って設計しています。

### ゲームの流れ

- **村パート**: カードをドラッグ&ドロップで重ね、素材の合成・施設の建設・スライムの配合や育成を行う
- **ダンジョンパート**: 編成したスライムのパーティーが半自動で戦闘し、新しい素材を持ち帰る
- 持ち帰った素材で新しいスライムや施設を作り、より奥のダンジョンへ

素材の入手先をダンジョンに一本化し、「ダンジョンで素材を集める→村で合成する」というループが
自然に回るようにしています。

## 実装済みの機能

### 村パート

- カードのドラッグ&ドロップ・スタック・合成システム
- レシピデータ(ScriptableObject)による合成判定。異なる種類の組み合わせ・同種固定枚数の組み合わせに対応
- 食料・月齢システム、マナクリスタルの自動生成
- ガチャ、スライムの配合・進化
- マナクリスタルによる経験値付与・レベルアップ(スタックをまとめてドロップすると一括処理)
- アクセサリーの装備システム(1スロット制。ドラッグ&ドロップで着脱し、装備中はステータスに補正がかかる)

### ダンジョンパート

- ウェーブ単位で敵が出現する半自動戦闘
- ダンジョンの木構造による解放(親をクリアすると子が解放、複数の親を必要とする合流ノードにも対応)とツリー画面
- 近距離/遠距離タイプ別の移動・射程・命中判定(Physics2D コライダーベース)
- 火・水・草・光・闇のタイプ相性によるダメージ補正
- 必殺技の範囲攻撃(単体/円形/直線/左右スイープ)
- 自動ターゲット選択: 各ユニットが索敵半径内の相手からランダムに選び、気絶するまで保持(毎フレーム再抽選によるちらつきを防止)
- 気絶システム(HP0でも消滅せず、一定まで回復するまで再編成不可)
- クリア報酬の素材ドロップ、パーティーHUD、ダメージポップアップ

## 技術スタック

- Unity 6(6000.5.6f1)/ 2D URP
- C#
- ScriptableObjectによるデータ駆動設計(スライム種族・レシピ・ダンジョンなど)

## 設計で工夫した点

- **レシピシステムの拡張判断**: 同じ素材を可変枚数受け付けるレシピが必要になった際、マッチング
  アルゴリズムを大きく作り変える案と、ドロップ側で1枚ずつ自動で繰り返し合成する軽量な案を比較し、
  既存の仕組みを壊さない後者を採用した
- **ターゲット選択のちらつき対策**: ランダムにターゲットを選ぶ仕様にしたところ毎フレーム対象が
  変わる問題が起きたため、選んだ対象をキャッシュして気絶まで保持する設計にした
- **ダンジョン内の敵構成のウェーブ化**: 1体ずつの単純なリストから、ウェーブ単位
  (`EncounterWaveData`)の構造へ置き換えた。1ウェーブに複数体が同時出現するケースと、
  「時間待ちで出現」「前ウェーブを全滅させた直後に即座に出現」という2種類の出現条件を
  表現する必要があったための変更
- **ダンジョン解放の木構造化**: ダンジョンの解放を一直線の進行ではなく、親子関係を持つ
  木構造にした。`ParentDungeons`を単一ではなく配列で持たせることで、複数の親ダンジョンを
  全てクリアしないと解放されない合流ノードも、特別な分岐コードを書かずにデータの持たせ方
  だけで表現できるようにした
