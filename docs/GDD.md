# slimelands ゲームデザイン文書 (GDD)

## コンセプト
Stacklands(カード積み重ね式の村運営)と「ゆっくり育てていってね」(半自動ダンジョン戦闘)を組み合わせた、スライム育成×村運営×ダンジョン攻略ゲーム。
人間ではなくスライムが村人となり、合成・配合・ガチャで様々な種類のスライムを生み出し、パーティーを組んでダンジョンに挑む。

## ゲームループ

```
村パート
├─ 合成(カード重ね) → 基本種スライム
├─ 配合(既存スライム + 素材) → 上位種スライム
│   └─ 異なるタイプ同士 / 同じタイプ同士、どちらの組み合わせも存在し、結果が変わる
├─ ガチャ(召喚) → 全種類が排出対象(確率は種類ごとに異なる)
├─ 制作 → 武器・防具・アクセサリー(ダンジョン産の素材が必要)
└─ 育成 → レベルアップ(マナ鉱石を消費)、進化(ダンジョン産の素材が必要)

    ↓ パーティーを編成してダンジョンへ出発

ダンジョンパート
├─ 複数種類のダンジョンが存在("ゆっくり育てていってね"踏襲)
├─ ダンジョンごとに必要な体数・出現する敵(既存のSlimeSpeciesDataを流用)が設定されている
├─ マップ移動は簡略化し、一定間隔で次の敵と自動的に遭遇する
├─ 戦闘は半自動進行。プレイヤーが操作するのは以下のみ:
│   ├─ 必殺技の発動タイミング(クールタイム制)
│   └─ 攻撃対象(ターゲット)の指定(タップで固定、対象が倒れると自動照準に戻る)
├─ タイプ相性が戦闘のダメージ計算に影響する(下記「タイプ相性」参照)
├─ パーティー全員が気絶した時点でダンジョン失敗(途中離脱・撤退はなし)
└─ ダンジョン内の敵を全て倒せばクリアで素材がドロップ

    ↓ 素材を持ち帰る

村パートへ還元(ループ)
```

## スライムの入手方法

| 方法 | 役割 |
|---|---|
| 合成(カード重ね) | 基本種の入手 |
| 配合(既存スライム+素材) | 上位種の入手。属性の組み合わせで結果が変化 |
| ガチャ(召喚) | 全種類が対象。レア度により排出確率が異なる |

## スライムのステータス

- **才能値・個体値**のような隠しパラメータを持ち、同じ種類でも個体差が出る
- **スキル**は複数持てるが、数を絞ってシンプルさを保つ(詳細な上限数は今後調整)

## タイプ相性(戦闘への影響、確定仕様)

- 火は草に強い/草は水に強い/水は火に強い(三すくみ)
- 光と闇はお互いに強い(双方向)
- 無属性はどのタイプとも相性なし
- 有利な attacker → defender の場合、ダメージに+20%(仮値、要調整)の補正がかかる。
  不利な側の減算は今回は設定していない(有利側のみの片方向ボーナス)
- 実装は`TypeAffinityData`(ScriptableObject)で、attacker/defenderの組み合わせと倍率をInspector上で編集できる

## リソース

| リソース | 入手方法 | 用途 |
|---|---|---|
| 資源(木材など) | 採掘・伐採などの生産活動 | スライムの食料(生のまま与えても良いが、料理すると食料値の回復量が大きい) |
| マナ鉱石 | 時間経過で自然回復 | レベルアップに使用 |
| ダンジョン産素材 | ダンジョンクリア報酬 | 配合・進化・武器防具アクセサリーの制作に使用 |

## 村の施設(Stacklands踏襲)

- 採石場
- 伐採場
- 納屋
- 鉱山
- 神殿(独自要素:気絶したスライムを復活させる)
- (他、村運営に必要な施設を今後追加検討)

## リスク・ゲームオーバー要素

- **ダンジョンでの気絶**: スライムは死なず気絶のみ。HPが回復するまで次のダンジョンに参加不可。経験値やステータスへの恒久的なペナルティはなし
- **村の食料切れ**: Stacklands同様、村の月齢が経過するタイミングで食料が尽きると村がゲームオーバーになる
- **神殿**: 気絶したスライムを復活させられる施設
